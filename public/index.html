Email Pixel Tracker

Academic demonstration of email open tracking via a 1×1 transparent GIF.

How it works

When an HTML email contains an <img> tag pointing to this server, the recipient's email client fetches the image on open. The server records the timestamp, IP address, user-agent, and any custom tracking ID — then returns the invisible pixel so the recipient notices nothing.

Embed in an email

<img
  src="https://YOUR-DOMAIN.vercel.app/api/pixel?id=YOUR_ID"
  width="1" height="1" style="opacity:0;"
/>

Replace YOUR_ID with any label (e.g. laptop_test) to identify which email or recipient triggered the hit.
